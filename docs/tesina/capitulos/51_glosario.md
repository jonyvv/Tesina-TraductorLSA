# Glosario

Los términos de este glosario aparecen en **negrita** en el lugar del cuerpo del documento donde se definen, indicado entre paréntesis.

Tabla: Glosario de términos técnicos. {#tab:glosario}

| Término | Definición |
|---|---|
| **Alfabeto manual** | Conjunto de configuraciones de la mano que representan las letras del alfabeto, usado para deletrear (sección 1.3.3). |
| **Aprendizaje automático** | Rama de la inteligencia artificial que estudia algoritmos que mejoran su desempeño a partir de datos (sección 2.2). |
| **Aprendizaje profundo** | Aprendizaje automático con redes neuronales de muchas capas, que aprenden sus propias representaciones (sección 3.2). |
| **Aprendizaje supervisado** | Aprendizaje a partir de ejemplos acompañados de la respuesta correcta (sección 2.2). |
| **Aumentación de datos** | Generación de variantes artificiales de los ejemplos de entrenamiento mediante transformaciones que no cambian su clase (sección 3.4). |
| **BiLSTM** | Red LSTM bidireccional: dos LSTM que recorren la secuencia en sentidos opuestos (sección 3.7). |
| **Características** | Valores numéricos que describen una entrada para un modelo de aprendizaje automático; en inglés, *features* (sección 2.2.1). |
| **Clasificación** | Tarea de asignar cada entrada a una de un conjunto finito de clases (sección 2.2.1). |
| **Comunidad sorda** | Personas que comparten la lengua de señas como lengua principal, con identidad y cultura propias (sección 1.1). |
| **Dropout** | Técnica de regularización que desactiva neuronas al azar durante el entrenamiento (sección 3.4). |
| **Época** | Pasada completa por todo el conjunto de entrenamiento (sección 3.3.2). |
| **Etiqueta** | Respuesta correcta asociada a un ejemplo de entrenamiento (sección 2.2). |
| **Exactitud** | Proporción de ejemplos clasificados correctamente; en inglés, *accuracy* (sección 2.5.1). |
| **Fuga de datos** | Filtración de información del conjunto de prueba al entrenamiento, que produce estimaciones optimistas (sección 2.4.2). |
| **Inteligencia artificial** | Área de la informática que desarrolla sistemas capaces de realizar tareas que requieren inteligencia (sección 2.1). |
| **Landmarks** | Puntos de referencia del cuerpo o de la mano estimados en una imagen; en este trabajo, 21 por mano (sección 4.2.2). |
| **Leave-one-subject-out** | Validación en la que cada persona queda, por turno, como conjunto de prueba de un modelo entrenado sin ella (sección 2.4.3). |
| **Lengua de Señas Argentina** | Lengua natural visoespacial de la comunidad sorda argentina, reconocida por la Ley 27.710 (sección 1.3). |
| **LSA64** | Conjunto de datos público de 3200 videos de 64 señas de la LSA (sección 5.2.1). |
| **LSTM** | Red recurrente con celda de memoria y compuertas que permite aprender dependencias de largo plazo (sección 3.6). |
| **Matriz de confusión** | Tabla que cruza las clases reales con las predichas y muestra cada tipo de error (sección 2.5.3). |
| **MediaPipe** | Marco de trabajo de Google para procesos de percepción; su solución de manos estima 21 puntos por mano (sección 4.3). |
| **Red neuronal artificial** | Modelo compuesto por unidades simples interconectadas cuyos parámetros se ajustan a partir de datos (sección 3.1). |
| **Redes neuronales recurrentes** | Redes que procesan secuencias manteniendo un estado que resume lo visto (sección 3.5). |
| **Regularización** | Conjunto de técnicas que limitan el sobreajuste (sección 3.4). |
| **Sobreajuste** | Situación en que un modelo aprende particularidades del entrenamiento que no generalizan (sección 2.3). |
| **WebSocket** | Protocolo de comunicación persistente y bidireccional entre navegador y servidor (sección 6.3). |
