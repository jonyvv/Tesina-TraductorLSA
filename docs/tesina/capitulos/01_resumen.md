# Resumen

Las personas sordas que se comunican en Lengua de Señas Argentina (LSA) enfrentan barreras cotidianas cuando interactúan con personas oyentes que no conocen esa lengua, y la disponibilidad de intérpretes humanos es limitada. Esta tesina presenta el diseño, la implementación y la evaluación de un sistema que reconoce señas aisladas de la LSA a partir del video de una cámara web convencional y las traduce a texto en tiempo real, accesible desde un navegador.

El sistema se organiza en tres capas. Un cliente web captura el video de la cámara, lo envía al servidor mediante un canal **WebSocket** y presenta la traducción junto con un esqueleto de la mano superpuesto a la imagen. Un backend desarrollado en Python con FastAPI extrae, para cada cuadro, los 21 puntos de referencia de cada mano con **MediaPipe** Hands y construye un vector de 138 características normalizado respecto de la posición y el tamaño de la mano. Una red neuronal recurrente bidireccional (**BiLSTM**), entrenada con PyTorch sobre el conjunto de datos público **LSA64** (3200 videos, 64 señas, 10 personas), clasifica la secuencia de vectores. Un módulo de código compartido garantiza que el preprocesamiento sea idéntico durante el entrenamiento y la inferencia.

El modelo se evaluó con validación **leave-one-subject-out**, es decir, midiendo siempre el desempeño sobre una persona que el modelo nunca vio durante el entrenamiento. Bajo ese protocolo se obtuvo una exactitud media de 79,8 % ± 8,9 % sobre las 64 clases, con una variación entre personas de 63,1 % a 89,5 %. El análisis de errores mostró que la principal fuente de variación es la proporción de cuadros en que MediaPipe no detecta las manos, y que las confusiones se concentran en señas que comparten configuración manual y difieren en la ubicación. Se documentan además los defectos metodológicos detectados y corregidos durante el desarrollo —etiquetado incorrecto, fuga de datos entre entrenamiento y prueba, orientación inconsistente de la imagen y entrenamiento no reproducible—, que invalidaban las mediciones iniciales.

**Palabras clave:** Lengua de Señas Argentina, reconocimiento de lengua de señas, aprendizaje profundo, LSTM bidireccional, MediaPipe, LSA64, aplicación web en tiempo real, accesibilidad.

## Abstract

Deaf people who communicate in Argentine Sign Language (LSA) face daily barriers when interacting with hearing people who do not know the language. This thesis presents the design, implementation and evaluation of a web-based system that recognizes isolated LSA signs from a standard webcam and translates them into text in real time. A browser client streams frames over a WebSocket to a FastAPI backend, which extracts hand landmarks with MediaPipe Hands, builds a 138-dimensional normalized feature vector per frame, and classifies the sequence with a bidirectional LSTM trained on the public LSA64 dataset. Evaluated with leave-one-subject-out cross-validation, the model reaches a mean accuracy of 79.8 % ± 8.9 % over 64 signs on unseen signers. Error analysis shows that performance is strongly associated with hand-detection rate and that confusions concentrate on signs sharing handshape but differing in location.

**Keywords:** Argentine Sign Language, sign language recognition, deep learning, BiLSTM, MediaPipe, LSA64, real-time web application.
